# Antigravity bundle

Register `mcp.json` in Antigravity's MCP settings and load `ANTIGRAVITY.md`
as the workspace instruction file. This is the native MCP/rules form because
Antigravity does not expose a portable third-party plugin manifest.

Copy `workflows/*.md` into a workspace or global Antigravity workflow
directory (per Antigravity's Workflows docs) for `/scos-recall`,
`/scos-explain`, `/scos-status`.
