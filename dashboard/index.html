Connect a local agent
 

These 14 runtimes are the local coding agents SCOS ships a bundle for (integrations/agent-plugins/registry.json). Install writes are additive and back up any file they touch — nothing here runs against your machine from the browser; run the command locally, then optionally paste its --json output below.

RUNInstall / refresh all bundles
python3 scripts/install_agent_plugins.py
RUNCheck status (this machine)
python3 scripts/agent_integration_doctor.py --json
Connect this machine to your account

Generates a one-time install link tied to your account. Running it on this or any machine writes ~/.hermes/scos.env and links every local agent bundle above to your account automatically — no gateway URL, bearer token, tenant ID, or principal ID to copy by hand.

⚠ one-time link, expires in 10 minutes and stops working once run — treat it like a temporary password
Load a doctor report

Paste the JSON printed by python3 scripts/agent_integration_doctor.py --json to overlay real per-agent status (VERIFIED / PRESENT / MISSING) on the list above. This never leaves your browser — it's parsed and rendered locally, not uploaded anywhere.
